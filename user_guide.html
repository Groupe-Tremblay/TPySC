TPSC

TPSC calculation are handled by the TPSC class.

class tpysc.Tpsc(mesh: Mesh2D, dispersion: numpy.ndarray)

Set up and run a Two-Particle Self-Consistent (TPSC) calculation.

The calculation is performed using the solve() method, which runs the first and second levels of approximation and checks self-consistency between one- and two-particle quantities.

Variables:

  • mesh (Mesh2D) – Two-dimensional momentum/frequency mesh used for the calculation.

  • dispersion (numpy.ndarray) – Array containing the dispersion values defined on the mesh.

  • g1 (numpy.ndarray or None) – Green’s function at the first level of approximation, G1(k, iwn). None until calc_g1() has been called.

  • g1_tau_r (numpy.ndarray or None) – G1(r, tau), the first-level Green’s function transformed to direct (real space, imaginary time) space. None until calc_g1() has been called.

  • g1_tau_mr (numpy.ndarray or None) – G1(-r, tau), the first-level Green’s function transformed to direct space with the real-space coordinate mirrored. None until calc_g1() has been called.

  • mu1 (float or None) – Chemical potential at the first level of approximation. None until calc_g1() has been called.

  • chi1 (numpy.ndarray or None) – Irreducible susceptibility chi1(q, iqn). None until calc_chi1() has been called.

  • trace_chi1 (complex) – Trace of chi1(q, iqn), computed as a consistency check. Not set until calc_first_level_approx() has been called.

  • Usp (float) – Irreducible spin vertex. Set to -1.0 as a default value until calc_usp() has been called.

  • chisp (numpy.ndarray) – Spin susceptibility chisp(q, iqn). Not set until calc_first_level_approx() has been called.

  • docc (float) – Double occupancy. Set to -1.0 as a default value until calc_double_occupancy() has been called.

  • Uch (float) – Irreducible charge vertex. Set to -1.0 as a default value until calc_uch() has been called.

  • chich (numpy.ndarray) – Charge susceptibility chich(q, iqn). Not set until calc_first_level_approx() has been called.

  • g2 (numpy.ndarray or None) – Green’s function at the second level of approximation, G2(k, iwn). None until calc_second_level_approx() has been called.

  • mu2 (float or None) – Chemical potential at the second level of approximation. None until calc_second_level_approx() has been called.

  • self_energy (numpy.ndarray or None) – Second-level (TPSC) self-energy, Sigma(k, iwn), excluding the Hartree term. None until calc_second_level_approx() has been called.

  • main_results (dict) – Dictionary summarizing the results of the TPSC calculation, populated by solve().

  • trace_self_g1 (complex or None) – Trace of the product of the self-energy with G1, Tr[Sigma * G1]. None until check_self_consistency() has been called.

  • trace_self_g2 (complex or None) – Trace of the product of the self-energy with G2, Tr[Sigma * G2]. None until check_self_consistency() has been called.

  • exact_trace_self_g (float) – Expected value of Tr[Sigma * G1] from the exact sum rule, U * docc - U * n^2 / 4, used by check_self_consistency() as a self-consistency check. Not set until check_self_consistency() has been called.

calc_double_occupancy(n: float, U: float) → float

Compute the double occupancy \(\langle n_\uparrow n_\downarrow \rangle\).

calc_usp() must be called before this method. The TPSC ansatz used here satisfies particle-hole symmetry, giving a piecewise expression in terms of the irreducible spin vertex Usp:

\[\begin{split}\langle n_\uparrow n_\downarrow \rangle = \begin{cases} \dfrac{U_\mathrm{sp}}{4U}\, n^2 & \text{if} ~ n < 1 \\ \dfrac{U_\mathrm{sp}}{4U}\, (2-n)^2 - 1 + n & \text{if} ~ n \geq 1 \end{cases}\end{split}\]
Parameters:

  • n (float) – Electron filling (density per site).

  • U (float) – On-site Hubbard interaction strength.

Returns:

The double occupancy.

Return type:

float

calc_g1(n: float) → None

Compute the first-level Green’s function G1 and its real-space transforms.

Finds the chemical potential mu1 that yields the target density n by root-finding on the non-interacting density, then computes G1(k, iwn) and its Fourier transforms to direct space, G1(r, tau) and G1(-r, tau).

Parameters:

n (float) – Electron filling (density per site).

calc_uch(n: float, U: float, Uchmin=0.0, Uchmax=100.0) → float

Function to compute Uch from chi1 and the sum rule. Note: calc_usp has to be called before this function.

Parameters:

  • U (float) – On-site Hubbard interaction strength.

  • Uchmin (float) – Lower bound of the search interval for Uch. Defaults to 0.

  • Uchmax (float) – Upper bound of the search interval for Uch. Defaults to 100.

Returns:

The irreducible charge vertex Uch solving the charge susceptibility sum rule.

Return type:

float

Function to compute Usp from chi1 and the sum rule.

Parameters:

  • n (float) – Electron filling (density per site).

  • U (float) – On-site Hubbard interaction strength.

Returns:

The irreducible spin vertex Usp solving the spin susceptibility sum rule.

Return type:

float

calc_xisp_commensurate() → float | None

Compute the spin correlation length from commensurate spin fluctuations at Q=(pi,pi). This calculates the width at half maximum of the spin susceptibility ONLY if its maximal value is at (pi,pi). If the spin susceptibility maximum is not at (pi,pi) (incommensurate spin fluctuations), this function returns -1.

Mesh2D

The k-grid and imaginary-time/Matsubara-frequency sampling grids are handled by the Mesh2D class.

class tpysc.Mesh2D(nk1: int, T: float, wmax: float, IR_tol: float = 1e-12)

Hold the k-grid and the sparsely sampled imaginary-time and Matsubara-frequency grids for a 2D system.

Defines the Fourier transform routines between real space and k-space (‘r’ <-> ‘k’) and between imaginary time, the intermediate representation, and Matsubara frequency (‘tau’ <-> ‘l’ <-> ‘iw_n’). Valid only for the 2D case.

Credit for the basics: Niklas Witt, https://spm-lab.github.io/sparse-ir-tutorial/src/TPSC_py.html

Variables:

  • T (float) – Temperature.

  • IR_basis_set (sparse_ir.FiniteTempBasisSet) – Intermediate representation basis set used for fermionic and bosonic sampling.

  • nk1 (int) – Number of k-points along the first dimension.

  • nk2 (int) – Number of k-points along the second dimension. Equals nk1.

  • nk (int) – Total number of k-points in the mesh (nk1 * nk2).

  • k1 (np.ndarray) – Meshgrid of k-point coordinates along the first dimension, normalized to [0, 1) (i.e. k/2*pi).

  • k2 (np.ndarray) – Meshgrid of k-point coordinates along the second dimension, normalized to [0, 1) (i.e. k/2*pi).

  • iw0_f (int) – Index of the lowest fermionic Matsubara frequency (n=1) in the IR basis.

  • iw0_b (int) – Index of the lowest (zero) bosonic Matsubara frequency in the IR basis.

  • iwn_f (np.ndarray) – Fermionic Matsubara frequencies i*wn.

get_specific_wn(statistics: str, obj_wn: numpy.ndarray, n_array: int | float | list | np.ndarray) → numpy.ndarray

Evaluate a sparsely-sampled Matsubara-frequency object at specific Matsubara frequency indices.

Takes a list of Matsubara frequency indices (n=0, ±1, ±2, …) and evaluates obj_wn at those frequencies. If obj_wn is multi-dimensional, the wn axis must be the first one.

Parameters:

  • statistics (str) – Statistic type, ‘f’ for fermionic or ‘b’ for bosonic. Case-insensitive.

  • obj_wn (np.ndarray) – Object sampled on the sparse Matsubara-frequency grid, with the frequency axis first.

  • n_array (int or float or list or np.ndarray) – Matsubara frequency indices n at which to evaluate the object. Accepts a scalar, a list, or a numpy array.

Returns:

The object evaluated at the requested Matsubara frequencies, with any length-one axis removed.

Return type:

np.ndarray

Raises:

  • TypeError – If n_array is not an int, float, list, or np.ndarray.

  • ValueError – If statistics is not ‘f’ or ‘b’ (case-insensitive).

trace(statistic: str, obj: numpy.ndarray, tau_value: float = 0) → float

Compute the sum over wavevectors and Matsubara frequencies of obj.

Average obj over the k-grid, then sum over Matsubara frequency via the intermediate representation basis by evaluating it near tau=0. tau_value must be 0 or beta (1/T), since the basis functions are defined only for tau in [0, beta]; these give the tau=0+ and tau=0- limits of obj’s imaginary-time counterpart, which is discontinuous at tau=0.

\[\mathrm{tr}\{O\} = \frac{T}{N}\sum_{\mathbf{k}}\sum_{i\omega_n} O(\mathbf{k}, i\omega_n)\, e^{i\omega_n 0^\pm}\]
Parameters:

  • statistic (str) – Statistic type, ‘f’ for fermionic or ‘b’ for bosonic. Case-insensitive.

  • obj (np.ndarray) – Object sampled on the sparse Matsubara-frequency grid and defined on the k-grid, with the Matsubara-frequency axis first and the k-axes second and third (axes 1 and 2).

  • tau_value (float) – Imaginary time at which to evaluate the trace: 0 for the tau=0+ limit, or beta (1/T) for the tau=0- limit. Defaults to 0.

Returns:

The trace evaluated at tau_value.

Return type:

float

Raises:

ValueError – If statistic is not ‘f’ or ‘b’ (case-insensitive).

tpysc.dispersions.calcDispersion2DSquare(mesh: Mesh2D, t=1.0, tp=0.0, tpp=0.0) → numpy.ndarray

Compute the tight-binding dispersion for a 2D square lattice.

Evaluates \(\epsilon(\mathbf{k})\) on the k-grid held by mesh, including nearest-, next-nearest- (diagonal), and third-nearest-neighbor hopping:

\[\epsilon(\mathbf{k}) = -2t\,(\cos(k_x) + \cos(k_y)) - 4t'\,\cos(k_x)\cos(k_y) - 2t''\,(\cos(2 k_x) + \cos(2 k_y))\]
Parameters:

  • mesh (Mesh2D) – Two-dimensional k-grid on which to evaluate the dispersion.

  • t (float) – Nearest-neighbor hopping amplitude. Defaults to 1.

  • tp (float) – Next-nearest-neighbor (diagonal) hopping amplitude. Defaults to 0.

  • tpp (float) – Third-nearest-neighbor hopping amplitude. Defaults to 0.

Returns:

The dispersion evaluated on the mesh’s k-grid, with the same shape as mesh.k1.

Return type:

numpy.ndarray
