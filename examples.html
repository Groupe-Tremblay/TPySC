Examples

A simple calculation

This example walks through a minimal TPSC calculation, from setting up the mesh to writing out the results. Download the full script: examples/simple_calculation.py.

Start by importing tpysc and, optionally, enabling console logging to print the progress of the self-consistency loop as it runs:

import logging

import tpysc

# Enable console logging to see the progress of the calculation.
tpysc.enable_console_logging(level=logging.INFO)

Group the TPSC input parameters into three dictionaries: the mesh (temperature, k-grid resolution and intermediate-representation settings), the tight-binding dispersion (hopping amplitudes), and the TPSC parameters themselves (interaction strength and filling):

# Pack the TPSC input parameters into dictionaries
parameters = {
    "mesh": {
        "T": 0.1,          # Temperature
        "nk1": 64,         # Number of k-points in one space direction
        "wmax": 8,         # For IR basis
        "IR_tol": 1e-12,   # For IR basis, tolerance of intermediate representation
    },
    "dispersion": {
        "t": 1,            # First neighbour hopping
        "tp": 1,           # Second neighbour hopping
        "tpp": 0,          # Third neighbour hopping
    },
    "tpsc": {
        "U": 2.0,          # On-site Hubbard interaction strength
        "n": 1,            # Electron filling (density per site)
    },
}

Build the mesh and dispersion from those dictionaries: the mesh sets up the k-grid and the imaginary-time/Matsubara-frequency sampling grids, and the dispersion evaluates the band energy on it:

mesh = tpysc.Mesh2D(**parameters["mesh"])
dispersion = tpysc.dispersions.calcDispersion2DSquare(mesh, **parameters["dispersion"])

Create a tpysc.Tpsc solver from the mesh and dispersion, and run it to self-consistency:

tpsc = tpysc.Tpsc(mesh, dispersion)
tpsc.solve(**parameters["tpsc"])

Finally, print the solver for a quick summary and write its results to a JSON file for later post-processing:

print(tpsc)
tpsc.writeResultsJSON("main_results.json")
